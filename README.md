# DevMetrics - Developer Analytics Platform

A MERN stack application that helps developers track coding productivity and collaborate with teams.

## Features
- 🔐 GitHub OAuth Authentication
- 📊 Personal commit analytics
- 👥 Team collaboration
- 🏆 Team leaderboards
- 📈 Interactive heatmaps

## Setup
```bash
# Install backend
cd server && npm install

# Install frontend  
cd client && npm install

# Create .env files and add your GitHub OAuth keys

# Run backend
npm run dev

# Run frontend (new terminal)
cd client && npm run dev
